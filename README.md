# Vibes & Trimz Booking App

This is a free, mobile-friendly booking webpage.

## What it does
- Shows services and prices
- Offers home studio and home service bookings
- Collects customer details
- Sends the completed booking request directly to WhatsApp
- Uses the WhatsApp number +44 7586 735046

## Important limitation
This version does not automatically reserve slots or store bookings in a database. A booking is confirmed only when you reply to the customer on WhatsApp.

## How to publish it for free
1. Create a free GitHub account.
2. Create a new public repository.
3. Upload index.html, styles.css and app.js.
4. Open repository Settings > Pages.
5. Set the source to the main branch and root folder.
6. GitHub will give you a free public link.

You can place the link in Instagram, TikTok, Facebook, WhatsApp Business or turn it into a QR code.

## Changing available times
Open index.html and edit the time options inside the Preferred time dropdown.
